# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in MetroCrawl, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, contact us directly at: **rajkaran@digitalmetro.dev**

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 5 business days
- **Resolution**: Based on severity

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.0.x   | Yes       |
| < 2.0   | No        |

## Scope

This policy covers the MetroCrawl application and all associated components:
- Crawler engine
- Kafka Monitor
- Redis Monitor
- REST Service
- Utility libraries

## Proprietary Notice

This software is proprietary. Security researchers must not retain, distribute,
or disclose any source code, architecture details, or implementation specifics
discovered during vulnerability research without written authorization from
Digital Metro.
